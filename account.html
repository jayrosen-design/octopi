Connections

Optional cloud services. Values are stored in this browser and can be cleared at any time. For a hosted deployment, put them in octopi-config.js instead.

Where do I find this?
  1. Firebase console → Project settings → Your apps → Web app → SDK setup and configuration.
  2. Authentication → Sign-in method: enable Anonymous and Google.
  3. Authentication → Settings → Authorized domains: add this site's domain (localhost is included by default).
Where do I find this?
  1. Google Cloud console → APIs & Services → Enable the Google Drive API.
  2. Credentials → Create credentials → OAuth client ID → Web application.
  3. Add this site's origin (for example ) to Authorized JavaScript origins.

Research providers
